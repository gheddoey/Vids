# Cinematic set-design directive + quality gate (user, Nov 26 2026) — STANDING RULES

**Build locations, not backdrops. Direct scenes, don't just position characters.**
Keep the blocky voxel/R6 identity — sophisticated production design *with* that aesthetic, not photorealism.

1. **Depth, always three layers.** Foreground (objects entering frame, silhouettes, furniture,
   architecture), midground (characters, interactions, key set pieces), background (developed
   architecture, other rooms/buildings, secondary activity). Never a character in front of one flat wall.
   The world extends beyond the area around the characters.
2. **Feature-film set design.** Each location designed as a complete, believable place (e.g. a bar:
   counter, stools, tables, bottle shelves, fixtures, signage, windows, floor *and* ceiling; a courtroom:
   raised bench, witness stand, counsel tables, gallery, wall treatments, doors; outdoors: terrain,
   roads/paths, multiple buildings, vegetation, props, background structures, atmospheric depth).
3. **Cinematography.** Establishing/wide/medium/close/OTS/low/high/tracking/dolly/pan/push/pull.
   Foreground framing for depth. Not every shot symmetrical or front-on; vary compositions.
4. **Lighting tells the story.** Key, fill, rim, practicals, ambient, sun, window light, cinematic
   shadows, colour contrast, atmosphere. Interiors ≠ exteriors. No flat even light.
5. **Materials.** Wood grain, brick variation, stone, concrete, metal, glass, fabric, imperfections,
   wear, roughness differences, small architectural details. No identical surfaces.
6. **Alive.** Purposeful idle motion, gestures, background activity, foliage, particles, smoke,
   moving lights/reflections, weather.
7. **Blocking.** Intentional positions, distances, orientation, relation to set/props/camera and emotion.
   No straight lines facing camera unless the shot demands it.
8. **Continuity.** Same location = same architecture, furniture placement, light direction, materials.
   Reusable environments + camera setups.
9. **Workflow per environment:** analyse → design plan → layout & dimensions → FG/MG/BG → asset list →
   build → light → block → camera → ambient motion → **render test shots and inspect** → improve.
10. **Quality gate (no exceptions):** before moving to the next scene, render a preview *from the actual
    camera* and evaluate depth, architectural completeness, FG/BG composition, light/shadow, character
    integration, cinematic presentation. Game-map look / objects on a floor / flat backdrop = FAIL →
    revise and re-render. Only approve after it passes. Never claim a render/inspection that didn't happen.
